O caminho é escolhido no criador; o título avança por promoção. O personagem começa sem equipamento. Não é necessário apagar ou recriar o personagem para uma promoção. Uma promoção dá +3 ATQ e +3 DEF; etapas de habilidades 3, 4 e 5 requerem respectivamente promoções 20, 40 e 60, além de pontos, nível e pré-requisitos próprios. Habilidades antigas ficam guardadas, inclusive quando aguardam uma promoção para voltar a conceder efeitos.

Cada prova sorteia cinco perguntas, incluindo identidade de classe e programação. Mínimo: quatro acertos. Aos 20 é necessário concluir as oito missões executáveis. Aos 40, revisar projetos até TypeScript. Aos 60, revisar a trilha até desenvolvimento de jogos. Falhar não remove XP, itens ou educação; nova tentativa após 30 segundos. A promoção de cada classe fica registrada por personagem. Troca de classe conserva os títulos de cada caminho.

## Linha educacional

História principal: variáveis → operações → condições → laços → funções → arrays → objetos → depuração. O código é executado no interpretador didático com testes. As etapas exigem respectivamente níveis 1, 1, 2, 2, 3, 3, 4 e 4, com a anterior concluída.

Projetos posteriores: pensamento computacional → lógica/JavaScript → HTML/CSS → JavaScript no navegador → Git/GitHub → TypeScript/OO → React → Next.js → APIs/servidores/bancos → testes/depuração → segurança → estruturas de dados/algoritmos → arquitetura → IA → desenvolvimento de jogos. Os projetos liberam conforme nível e revisão do anterior. A revisão é registrada pelo estudante e não equivale a certificação automática. Rascunhos antigos permanecem, mesmo que uma etapa esteja bloqueada para progressão.

Missões secundárias com viajantes: primeiro contato com IA → pedidos claros para Claude → iteração/diagnóstico → repositório com Claude Code → permissões/segredos → testes/diff → ferramentas/contexto/MCP → avaliação/custo → agentes/segurança → projeto de maestria. Três cursos de dez etapas (Claude e IA, Claude Code, Claude Cowork) nos níveis 1, 3, 6, 10, 15, 20, 30, 40, 50 e 60. Cada curso tem sua própria sequência. Cada etapa tem explicação, atividade prática registrada e uma verificação de conceito. A pergunta não valida a qualidade completa da atividade: a evidência permanece para revisão. Repetir uma etapa não repete XP.

Referências oficiais consultadas em 04/11/2026: https://code.claude.com/docs/en/settings e https://support.claude.com/en/articles/14554922-claude-code-user-faq. Instruções específicas de versões e comandos devem ser conferidas na documentação atual. O jogo não instala Claude Code, conecta APIs nem utiliza serviços pagos.

## Baús

Três posições exploráveis, sem marcadores no minimapa. Cada baú exige proximidade, uma etapa principal e o nível adequado. A pergunta é sorteada entre conceitos já ensinados; errar não consome itens. Relíquias exclusivas ocupam o slot de relíquia e têm requisitos próprios. Uma recompensa por personagem e por baú. A importação de um save anterior do mesmo personagem conserva os registros de abertura para evitar repetição pelo fluxo normal do aplicativo.

## Preservação e limitações

Envelope de save versão 4, mesma chave. Backup antes da atualização. Novos campos: promoções e baús do personagem; etapas/evidências de IA e revisões de projeto na educação. Restauração conserva evidências permanentes e promoções do mesmo personagem. Hardcore reinicia a carreira do novo personagem, preservando a educação. Dados locais podem ser adulterados fora do jogo; não existe servidor antifraude.

O limite de nível continua 60. O balanceamento de XP, duração de cada etapa, força dos inimigos e custo dos itens precisa de sessões de jogo. A trilha está segmentada até maestria, mas conteúdos avançados ainda são roteiros de projeto e precisam de aulas aprofundadas e avaliação prática. Não declarar um curso profissional completo ou domínio por respostas memorizadas.

## Entrega e campanha

Missões principais: exclamação e interrogação amarelas. Secundárias: azul-claro. Resolver o exercício registra a aprendizagem e sua recompensa única; entregar o relatório ao mentor libera a etapa seguinte sem conceder a mesma recompensa outra vez. Dados antigos já concluídos são migrados como entregues.

Chefes de região desbloqueiam a sequência bosque → minas → ruínas → fronteira → coração do código. Nullarion é o chefe mestre nível 60. O jogo mantém as vitórias do mesmo personagem na restauração. O nome do perfil na entrada é local, sem autenticação online.
